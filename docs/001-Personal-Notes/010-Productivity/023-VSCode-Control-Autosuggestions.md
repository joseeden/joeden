## Problem

When editing YAML files in VS Code, suggestions may appear even when the current line is completely empty.

**EDIT:** This could also appear on other file types and even Untitled files. The issue is that VS Code may show suggestions even when no text has been entered yet.

For example, VS Code may immediately suggest:

```yaml
AWSTemplateFormatVersion: "2010-09-09"
```

This can be distracting because no text has been entered yet.

## Disable Automatic Suggestions in YAML

To stop VS Code from automatically showing suggestions in YAML files:

1. Open **VS Code Settings** with `Ctrl + ,`

2. Open `settings.json`.

3. Add:

```json
"[yaml]": {
    "editor.quickSuggestions": false
}
```

This disables automatic suggestion popups in YAML files.

You can still manually trigger suggestions using: `Ctrl + Space`

:::info

This setting does not disable autocomplete completely.

It only prevents VS Code from automatically showing suggestions while editing YAML files.

Manual suggestions are still available with: `Ctrl + Space`

::: 

## Disable Inline Suggestions Globally

Add this to the `settings.json` file to disable inline suggestions globally:

```json
"editor.inlineSuggest.enabled": false
```

This targets the behavior where VS Code or an extension puts a suggested completion on an otherwise empty line, usually as faint/ghost text.

Your normal IntelliSense can still work when you explicitly type or invoke it; this specifically disables those proactive inline completions.

If `AWSTemplateFormatVersion...` still appears after setting this to false, then it's almost certainly being generated by an extension such as AWS Toolkit, Copilot, or another completion extension rather than VS Code itself. In that case, you need to identify which extension is providing it and disable only that provider rather than all inline suggestions.

## Optional: Disable Enter from Accepting Suggestions

If you also want to prevent **Enter** from accepting an autocomplete suggestion, add:

```json
"editor.acceptSuggestionOnEnter": "off"
```

Or:

1. Open **Settings** with `Ctrl + ,`
2. Search for:

   `Accept Suggestion On Enter`

3. Set **Editor: Accept Suggestion On Enter** to **Off**.

:::info 

Disabling this affects autocomplete suggestions globally, not just YAML files.

Use this only if you do not want **Enter** to accept suggestions anywhere in VS Code.

:::

## Recommended Configuration

For the original issue, suggestions appearing automatically on empty YAML lines, use:

```json
"[yaml]": {
    "editor.quickSuggestions": false
}
```

Keep:

```json
"editor.acceptSuggestionOnEnter": "on"
```

if you still want **Enter** to accept normal autocomplete suggestions.
